# 🐱 Игра "Hungry Cat"

Простая 2D игра, где нужно управлять котиком, собирать рыбки и уворачиваться от врагов.

## 🎮 Управление

| Действие | Клавиши |
|----------|---------|
| Движение влево | `A` или `←` |
| Движение вправо | `D` или `→` |
| Выход из игры | `Esc` |
| Перезапуск | Кнопка "RESTART" |

## 🎯 Цель игры

- Собирай **золотые рыбки** — за каждую рыбку даётся 1 очко
- Уворачивайся от **красных врагов** — столкновение с врагом заканчивает игру
- Установи **новый рекорд** — набери больше всех рыбок за одну игру

## 🚀 Как запустить

### Требования:
- Windows 7, 8, 10, 11
- Установленный .NET Framework 4.5 или выше

### Запуск из Visual Studio
1. Открой файл решения `игра.sln` в Visual Studio
2. Нажми `F5` или кнопку **Запуск**
3. Наслаждайся игрой!

## 📁 Необходимые файлы

Для корректной работы игры в папке с `.exe` должны быть:

| Файл | Описание |
|------|----------|
| `f.jpg` | Фоновое изображение |
| `vecteezy_cute-cartoon-cat-halloween-character-pumpkin_9665797.png` | Изображение котика |
| `enemy.png` | Изображение врага |
| `fish.png` | Изображение рыбки |
| `musicFon.wav` | Фоновая музыка |
| `die.wav` | Звук проигрыша |

> ⚠️ Если картинки или звуки отсутствуют, игра будет работать, но вместо них будут отображаться цветные квадраты.

## 🎨 Оформление

- **Фон персонажей** — светло-жёлтый
- **Фон надписей** — светло-голубой
- **Цвет текста** — тёмно-синий
- Размер всех персонажей — **70x70 пикселей**

## 🐛 Возможные проблемы

### Игра не запускается
- Убедись, что установлен .NET Framework
- Переустанови игру
